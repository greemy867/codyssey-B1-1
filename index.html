모델별 총평

🥇 Claude Opus 4.8 — 34

7개 섹션 정확 준수. 화자가 불확실하게 말한 수치를 스스로 ⚠️로 분리해 환각을 가장 적극 차단. 네이티브라 즉시 응답·추가비용 없음. 약점: 주제 디테일은 GPT-5보다 다소 얕음.

🥈 GPT-5 — 32

주제별 8개 하위섹션으로 가장 상세. 사실·수치 테이블 최다(Vera Rubin 사양·CUDA 13.2 등). 약점: 템플릿을 다소 확장, 응답 느림 + 토큰 비용(43K) 큼.

🥈 Gemini 2.5 Pro — 32

형식·한국어·효율 우수, 출력 1.7K 토큰으로 가장 경제적. 불확실 수치 '확인 필요' 표기. 약점: 후반부 주제(게임/의식/죽음) 포착이 얕음.

🏆 최종 선정 결론 — Claude Opus 4.8

  1. 핵심 축인 형식 준수·환각 억제·반복 효율에서 Claude가 가장 균형적(34/35). 화자조차 불확실하게 말한 수치를 ⚠️로 분리해 환각을 능동 차단.
  2. GPT-5는 깊이는 최고였으나 느리고 비쌈, Gemini는 효율적이나 후반부 주제가 얕음.
  3. 세 모델 환각은 모두 0건(불확실 값은 전부 '확인 필요')이라 정확성은 동급 → 형식 일관성·속도·비용에서 Claude가 우위.
운영 권고: 기본 요약 = Claude · 심층 리서치 = GPT-5 · 빠르고 저렴한 대량 처리 = Gemini 2.5 Pro 로 역할 분담.

Codex의 반론 — Claude 1위 결론 점검

요지: 현재 점수표 안에서는 Claude 1위가 성립하지만, 객관적 성능 우위가 강하게 입증됐다고 보기는 어렵습니다. 더 정확한 결론은 "Claude와 GPT-5는 박빙이며, 운영 목적상 Claude를 기본 요약 모델로 채택"입니다.

  • 승부를 가른 축이 비용/속도입니다. Claude 34점과 GPT-5 32점의 차이는 주로 속도·안정성·비용 축에서 발생합니다. 다만 Claude의 실제 토큰 사용량, 응답 시간, API 비용이 기록되지 않았고, "API 유료" 기록과 "추가 비용 없음" 설명 사이에 해석상 충돌이 있습니다.
  • 심층성과 정보 포착력은 GPT-5가 더 강합니다. GPT-5는 8개 하위 섹션으로 가장 상세하게 전개했고, Vera Rubin 사양, CUDA 13.2, 43,000명 등 사실·수치 테이블도 가장 풍부했습니다. 보고서 자체도 GPT-5에 핵심 포착력 5점, 긴 문맥 처리 5점을 부여했습니다.
  • Claude의 장점은 형식과 폭넓은 커버리지입니다. Claude는 7개 섹션을 안정적으로 지키고 후반부 주제까지 넓게 훑었습니다. 특히 화자가 불확실하게 말한 CUDA 직전 시총을 별도 표시한 점은 환각 억제 측면에서 강점입니다.
  • 인용 정확성 5점은 다소 후합니다. 세 모델 모두 핵심 인용을 잘 잡았지만, 일부 인용은 원문 말끊김·부가 표현까지 완전히 보존하지 않았습니다. "원문 문장 그대로"라는 엄격 기준이면 감점 여지가 있습니다.
  • Gemini는 1위 후보로 보기는 어렵습니다. 형식과 한국어는 좋지만 주제별 요약이 리더십·스케일링·공급망 중심으로 압축되어, 게임·프로그래밍의 미래·의식·죽음 등 후반부 반영이 약합니다.
수정 권고: "Claude가 해당 task에서 제일 뛰어나다"보다는 "기본 요약 파이프라인은 Claude, 심층 리서치와 사실 망라는 GPT-5"로 표현하는 편이 더 방어 가능합니다.

  • AI 스케일링 전략: 전처리→후처리→테스트시점→에이전트 4단계. 데이터 부족은 합성 데이터로, 추론 병목은 컴퓨팅으로. 핵심은 전력 효율(tokens per watt).
  • 공급망·생태계 관리: ASML·TSMC 등에 미래 수요·로드맵 공유해 선제 투자 유도. 과거 HBM 설득이 대표 사례. TSMC 경쟁력=제조 조율 능력 + 신뢰.
