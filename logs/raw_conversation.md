### [Turn 2] 🤖 AI (요약봇)
## 📌 한 줄 요약
젠슨 황은 NVIDIA의 경쟁력을 'extreme co-design', 'CUDA install base 해자', '미래를 미리 설득해 실현하는 리더십'으로 설명하며, 컴퓨팅이 검색 창고에서 '토큰 공장'으로 이동했다고 진단합니다.

## 🎯 핵심 메시지
- 문제가 한 대의 GPU에 안 들어가므로 칩~데이터센터 전 스택을 동시 설계(extreme co-design)한다.
- 아키텍처의 성패는 우아함이 아니라 install base가 결정한다(x86 사례). NVIDIA 최대 해자는 CUDA.
- 스케일링 법칙은 사전학습→사후학습→테스트타임→에이전트로 확장되고, 결국 지능은 컴퓨트로 스케일된다.
- 컴퓨터의 목적이 '검색 창고'에서 매출을 만드는 'AI 공장'으로 바뀌었다.
- 지능은 상품(commodity)이며, 더 중요한 건 인간성·인격이다.

## 🗂️ 주제별 요약
- **Extreme co-design**: Amdahl 법칙 때문에 연산만 빨라도 병목이 네트워크·CPU로 이동 → 전 스택 공동설계.
- **리더십**: 직속 60명, 1:1 없음. 매일 신념 체계를 형성해 발표 시 100% buy-in.
- **스케일링/전력**: 합성 데이터로 데이터 한계 극복, 추론은 사고라 컴퓨트 집약. 전력망 유휴분 활용·graceful degradation 제안.
- **China/오픈소스/TSMC**: 세계 AI 연구자 ~50% 중국계. Nemotron 3 공개. TSMC는 기술+신뢰, 계약 없이 30년 거래.
- **AGI/일자리**: "이미 AGI 도달". 코딩=명세, 코더 3천만→10억. 방사선과 사례로 '직무 목적≠작업' 설명.

## 💬 주목할 인용
- "Install base defines an architecture. ... Everything else is secondary." — Jensen Huang
- "I always say that NVIDIA is the house that GeForce built." — Jensen Huang
- "We need things to be as complex as necessary, but as simple as possible." — Jensen Huang

## 🔢 사실·수치 주장 (검증 대상)
- 직속 스태프 60명 / Jensen Huang / 원문 근거 있음
- CUDA로 원가 약 50%↑, 당시 매출총이익률 35% / Jensen Huang / 원문 근거 있음

- 언급된 인수기업: Mellanox / Jensen Huang / 원문 근거 있음

## ⚠️ 확인 필요·불확실
